HUSA API Reference v1.0.0

Base URL: http://localhost:8080/api/v1

Authentication

All requests require: Authorization: Bearer JWT_TOKEN

POST /vms

Create a new synthetic VM.

Request Body

FieldTypeRequiredDescription
namestringYesVM name (3-255 chars)
workload_hintstringYesweb-server, database, generic
architecturestringNoX86_64, Aarch64, RiscV64
memory_bytesuint64YesRAM in bytes
storage_bytesuint64YesStorage in bytes
vcpu_countuint8Yes1-512
enable_checkpointingboolNoDefault: false
curl -X POST http://localhost:8080/api/v1/vms \
  -H "Authorization: Bearer TOKEN" \
  -d '{"name":"my-vm","workload_hint":"web-server","memory_bytes":536870912,"storage_bytes":10737418240,"vcpu_count":4}'

GET /vms

List all VMs. Pagination: offset, limit. Filter: state.

GET /vms/{id}

Get VM by ID. Returns 404 if not found, 410 if GDPR-erased.

POST /vms/{id}/transition

Change VM state. Valid transitions: Running-Paused, Paused-Running, Running-Stopped, Stopped-Destroyed.

DELETE /vms/{id}

GDPR soft delete. Data preserved for audit trail.

GET /health

System health check. No authentication required.
